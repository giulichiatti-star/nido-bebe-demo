# Nido Bebé · Web propia + panel de gestión

Demo navegable para NIDO BEBÉ (Rosario). Se abre directo en el navegador, sin instalar nada.

| Archivo | Qué es |
|---|---|
| `index.html` | La demo: web propia + panel (pedidos, etiquetas, stock, historial, dashboard y promociones) |
| `db/schema.sql` | Estructura de la base de datos del sistema real |

## Cómo probarla en 3 minutos

1. **Como clienta:** en la pestaña Web abrí la guirnalda, escribí un nombre, agregá unos portachupetes y enviá el pedido con el código `BIENVENIDA`.
2. **Como NIDO:** en Pedidos tocá las tarjetas para filtrar, confirmá el pago, imprimí la etiqueta y pasalo a producción.
3. **Stock y números:** en Stock mirá qué insumos se descontaron y registrá una compra. Después recorré el Historial y el Dashboard.

## Importante

- Es un **prototipo**: los pedidos, clientes y números son de ejemplo y se reinician al recargar la página.
- Los productos y descripciones salen del catálogo 2026. Las **recetas de insumos son estimaciones** que hay que validar con el taller.
