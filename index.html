Cómo probar el Esquema A en 3 minutos

1. Hacé un pedido como clientaEn la pestaña Web abrí la guirnalda, escribí un nombre, agregá unos portachupetes y enviá el pedido con el código BIENVENIDA.
2. Gestionalo como NIDOAndá a Pedidos: tocá las tarjetas para filtrar, confirmá el pago, imprimí la etiqueta y pasalo a producción.
3. Mirá el stock y los númerosEn Stock vas a ver qué insumos se descontaron. Registrá una compra. Después recorré el Historial y el Dashboard.
